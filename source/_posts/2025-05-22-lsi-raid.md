# 扩容

首先需要将待插入的硬盘设置为UGood状态：

```bash
sudo storcli /c0/e252/s5 set good force
```



接下来向现有阵列中添加该硬盘：

```bash
sudo storcli /c0/v0 start migrate type=raid5 option=add drives=252:5
```


阵列会开始重建，持续十几个小时



可以使用以下指令查看重建进度：

```bash
sudo storcli /c0/v0 show migrate
```
